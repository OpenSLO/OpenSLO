The July meeting covered JSON Schema, Backstage plugins, budgeting methods, and release planning after v1.

<!-- more -->

## Summary

1. **Schema and libraries**:
   A code-generation experiment favored handwritten libraries validated against JSON Schema. The group also discussed publishing the schema and keeping documentation examples consistent with it. [Discussion at 0:16](https://www.youtube.com/watch?v=3boka90T3qY&t=16s).

2. **Backstage plugins**:
   A repository and issues were ready for the plugins. TypeScript definitions could start there, with a shared library considered later. [Discussion at 2:51](https://www.youtube.com/watch?v=3boka90T3qY&t=171s).

3. **Ratio time slices**:
   A proposal would average each slice's success ratio instead of classifying slices as pass or fail. Participants favored exploring a separate budgeting method. [Discussion at 40:01](https://www.youtube.com/watch?v=3boka90T3qY&t=2401s).

4. **Release planning**:
   The group favored starting with quarterly specification releases and a shared roadmap. The discussion also covered composite SLO weights. [Roadmap discussion at 45:11](https://www.youtube.com/watch?v=3boka90T3qY&t=2711s).

## Action Items

1. Create a new roadmap board and invite contributors to prioritize issues.
2. Open an issue comparing the proposed time-slice designs.
