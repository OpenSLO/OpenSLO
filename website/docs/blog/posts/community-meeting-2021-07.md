The July meeting covered the 1.0 roadmap, a working demonstration, and ways to track SLO coverage across services.

<!-- more -->

## Summary

1. **Roadmap to 1.0**:
   GitHub project boards and milestones now tracked work for OpenSLO and oslo. Separate idea boards held proposals outside the immediate release scope, including work to separate SLIs from SLOs. [Discussion at 0:20](https://www.youtube.com/watch?v=xUC1vMztwug&t=20s).

2. **Demonstration from definition to alert**:
   Participants planned a demo that would connect an OpenSLO definition to data collection and alerting. They discussed both production monitoring and delivery checks, with Keptn examples as possible starting points. [Discussion at 4:47](https://www.youtube.com/watch?v=xUC1vMztwug&t=287s).

3. **SLO coverage**:
   The group explored checking a service catalog for missing or invalid SLO definitions. GitLab's internal catalog provided an example, while labels and annotations could help associate definitions with services. [Discussion at 16:56](https://www.youtube.com/watch?v=xUC1vMztwug&t=1016s).

## Action Items

1. Create a Slack channel and GitHub issue for the demo, with goals and expected outcomes.
2. Add an issue for service coverage and validation checks.
3. Invite contributors to refine the roadmap and help with the demo.
