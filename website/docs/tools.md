# Tools

## Oslo CLI

[Oslo](https://github.com/OpenSLO/oslo) validates and formats OpenSLO YAML and
JSON files.
Use it locally or in a CI/CD workflow to check your SLO definitions.
See the [installation instructions](https://github.com/OpenSLO/oslo#installation)
and [command examples](https://github.com/OpenSLO/oslo#usage).

## Go SDK

The [OpenSLO Go SDK](https://github.com/OpenSLO/go-sdk) provides types for OpenSLO
objects and functions to decode, validate, and encode them.
See its [usage examples](https://github.com/OpenSLO/go-sdk#usage) to integrate
OpenSLO into a Go application.

Use the [schema reference](schema.md) to check the fields and validation rules
for each API version.
